# 价值观问卷设计（v1 草稿）

## 设计原则

1. **短**：5 分钟内完成，15–20 题；
2. **可计算**：每题答案映射到 5 个维度（消费观/婚恋观/家庭观/职业规划/相处模式）的权重；
3. **不冒犯**：无收入、婚史、家庭背景等敏感问题；
4. **明示非诊断**：页面注明「结果仅供匹配参考，非心理诊断」，并提供学校心理中心入口；
5. **防作弊**：计分权重只存服务端，接口不下发。

## 题库（18 题完整草稿；代码库已内置前 10 题）

### A. 消费观（3 题）

1. 月底生活费紧张时，你倾向于？（规划开支 / 周转 / 随缘）
2. 约会开销你更认同哪种方式？（AA / 谁主动谁承担 / 无所谓）
3. 给另一半送礼，你更看重？（实用 / 惊喜仪式感 / 心意到了就行）

### B. 婚恋观（4 题）

4. 你对跨校区异地恋（济南/青岛/威海）的态度？（坚持 / 不接受 / 看感情）
5. 你理想的恋爱节奏？（细水长流 / 尽快确定 / 顺其自然）
6. 你认为恋爱中「个人空间」应该？（保持独立空间 / 尽量粘在一起 / 看情况）
7. 毕业后希望多久内稳定下来？（毕业即规划 / 先搞事业 / 顺其自然）

### C. 家庭观（3 题）

8. 毕业后倾向在哪里发展？（留山东 / 去一线 / 商量着来）
9. 双方家庭的参与程度？（常走动 / 小家庭独立 / 平衡）
10. 你如何看待「山东彩礼」等地域婚俗？（尊重并接受 / 看家庭情况 / 希望从简）

### D. 职业规划（4 题）

11. 学业/事业压力大时希望伴侣？（给建议 / 安静陪伴 / 各自处理）
12. 你目前的生活重心？（学业科研 / 恋爱 / 平衡）
13. 你对「恋爱影响学习」的看法？（可以相互促进 / 会有影响但值得 / 顺其自然）
14. 未来另一半的工作地要求？（必须同城 / 可以异地 / 可以商量）

### E. 相处模式（4 题）

15. 发生分歧时你更倾向？（当天说开 / 冷静后再谈 / 希望对方主动）
16. 你理想的相处状态？（各忙各但心里有 / 形影不离 / 介于之间）
17. 你更愿意怎么度过周末？（户外活动 / 宅 / 都有）
18. 你的表达风格？（直球型 / 含蓄型 / 看对象）

## 计分方法

- 每题每个选项给出 5 维权重 `w = [w1..w5] ∈ [-1, 2]`；
- 用户全部作答后按维度求和得到 `sum[i] = Σ w_i`；
- 对 `sum` 做 L2 归一化得到价值观向量 `v`；
- 匹配时计算双方向量的余弦相似度。

实现见 `packages/shared/src/constants/surveyQuestions.ts` 与 `packages/shared/src/matching/vector.ts`。
