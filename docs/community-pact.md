# SDUMeet 用户社区公约（v0.1）

欢迎来到 SDUMeet。为了让平台安全、友好、有效，请遵守以下公约。使用平台即视为同意。

## 一、真实与诚信

1. 一人一号，使用本人学号与真实信息认证；
2. 照片与自我介绍真实，不盗用他人照片；
3. 已脱单或注销后不再参与匹配。

## 二、尊重与边界

1. 尊重对方的性别、性取向、校区、专业与外貌；
2. 单方「心动」不会打扰对方，只有互相心动才解锁聊天；
3. 被拒绝不纠缠、不报复、不传播；
4. 未经对方同意，不截屏、不转发、不公开聊天记录与资料。

## 三、禁止行为

1. 性骚扰、言语攻击、威胁、人肉搜索；
2. 冒用身份、一人多号、代认证；
3. 诈骗、广告、引流、收费牵线；
4. 发布违法或低俗内容。

## 四、安全建议

1. 首次见面选择公共场所（校园、大明湖、商场等）；
2. 见面告知朋友并共享行程（可选功能：临时定位分享）；
3. 遇到骚扰或可疑行为，立即举报——我们会 24 小时内处理。

## 五、数据与隐私

1. 你的资料仅用于匹配，不向第三方出售；
2. 可随时注销账户，30 天内物理删除数据（法律要求保留的除外）；
3. 匹配报告基于问卷计算，非心理诊断。

## 六、违规处理

警告 → 限制匹配/聊天 → 封禁账号。对严重违法行为将配合有关部门处理。

*公约版本随产品迭代更新，重大变更会提前通知。*
